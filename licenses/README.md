# Third-party assets

The hat models (`src/main/resources/hats.zip`, the `.tbl` files that end up in the `hats` folder of the game) and the
textures, sounds, models and translations in `src/main/resources/assets/hatsreinvented` come from the
[Hats](https://github.com/iChun/Hats) mod by iChun and the hat makers named in each hat file, released under the
GNU LGPL-3.0 (`LGPL-3.0.txt`, which builds on `GPL-3.0.txt`).

Everything else is under the Don't Be an Asshole License in `../LICENSE.md`.
